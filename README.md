# intro.data_taller05
# ANALISIS DE CONTENIDO DE RELACIONES EN REDES SOCIALES
En este proyecto  se analiza  como se representan las relaciones interpersonales en  temas como el amor, celos, ruptura, independencia, deseo, etc. en los posts de las redes sociales.
# OBJETIVO
La misión en este proyecto es identificar patrones que se indentifiquen en el contenido de las redes sociales y que temas suelen mas predominar en este tipo de publicaciones.

# RECOLECCION DE LOS DATOS
Se hizo un dataset de 20 posts distintas clasificadas segun:
Tema: Celos, independencia, toxicidad
Tono: Positivo, neutro, negativo
Numero de interacciones: Likes
